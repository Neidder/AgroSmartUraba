# AgroSmart Urabá

Sistema de gestión y seguimiento de información agrícola para pequeños productores de Urabá.

## Estructura del proyecto
- `backend/`: API REST con Django y PostgreSQL.
- `frontend/` (o raíz): Interfaz de usuario con React, Vite y Tailwind CSS.

## Cómo ejecutar el Frontend
1. Instalar dependencias: `npm install`
2. Iniciar servidor: `npm run dev`
